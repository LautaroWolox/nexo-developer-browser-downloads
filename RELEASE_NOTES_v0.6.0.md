# NEXO Developer Browser v0.6.0 — Notas de versión preliminares

**Borrador. No se ha publicado la versión.**

- Navegador Chromium con pestañas, historial, descargas y favoritos.
- Inicio organizado por Backend, Frontend, patrones de diseño, comunidades
  y un catálogo de herramientas para desarrolladores.
- Postman, Hoppscotch, Apidog, Insomnia: accesos a los servicios oficiales.
- Lectura de código, JSON Toolbox y DevTools corregidos para páginas internas.
- SQL Studio Oracle Thin: conexión configurable, exploración de esquema,
  consultas parametrizadas de lectura, resultados y exportación CSV.
- Paquete Linux con ícono y acceso al menú de aplicaciones.

## Requisitos

Linux x86_64 para los primeros paquetes. Conexión a internet para sitios
externos; para bases Oracle privadas se requiere acceso a la red/VPN
correspondiente. Usar cuentas de consulta sin permisos de modificación.

## Limitaciones

Beta todavía no auditada ni firmada. No se garantiza inicio de sesión dentro
de Electron en Gmail y otros proveedores. No habilitar `--no-sandbox`.
